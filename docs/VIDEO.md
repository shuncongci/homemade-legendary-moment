# 视频模式 · 3.0.0 公开版

## 操作

1. 从编辑页进入视频，选择本次处理文件。仅复制所选文件到私有缓存，不扫描媒体库、不改原视频。
2. 查看系统/容器轨道信息；多条独立视频画面须明确选择，输出只包含所选画面和音轨，不合并其他画面。原容器预览由系统选轨，未必等于处理所选轨。
3. 左上角选择“徕卡一瞬”或“徕卡N瞬”。首次默认N瞬，只有显式保存默认选择才影响下次进入；选择后需点击调色。
4. 导入/成片准备后请求显示首帧并保持暂停，不以播放再暂停制造首帧；可播放、拖动、切原片/成片。真实播放器首帧行为仍待设备验收。
5. 调色完成后预览并导出。Android 10+ 默认保存到 `Movies/传奇一瞬/`，可另存为文件；较早系统使用文件选择器。不会覆盖原视频。

离开页面会停止处理中任务，中断后需重做。失败/取消保留原片和上次完整成片；缓存不是长期备份。若当前原片与上次成片不同，导出前会说明实际来源。

## 色彩资源

| 风格 | 路径 | 用途 |
|---|---|---|
| 徕卡一瞬 | `looks/leica-instant-v2.bin` | 与照片共用同一份 LUT 节点 |
| 徕卡N瞬 | `looks/leica-n-instant.bin` | 视频风格 |

两份均为明文公开的65³、Float64 LUT，哈希和字节数见 [资源清单](../models.json)。普通 JNI 库在验证格式和哈希后使用资源，不需要作者的签名、密钥或私有保护材料。它们与传奇专属色彩资源无关。

视频使用适配 SDR/HDR 的传递函数、色域与 YUV 转换，再重编码；相同 LUT 不表示照片与视频编码逐像素相同，也不代表模拟了官方相机。最多8线程分行处理**同一帧**，不并行重排8帧；不承诺手机稳定8倍加速。

## SDR、HDR 与杜比边界

- SDR 与 PQ/HLG HDR 分别按可核验色彩配置处理；保留原尺寸、画面比例和帧时序，不是压缩码流无损复制。
- HDR 需要 Android 13+ 及实际提供10bit P010输入输出的编解码器，不支持则明确停止；不会静默转8bit或SDR。
- 杜比只支持可核验的 Profile 8、兼容ID1/PQ或4/HLG、独立Main10/4:2:0基础层。输出为**普通HEVC**，移除旧RPU、杜比配置和动态元数据，不承诺保留杜比显示效果。
- Profile 5/IPT、增强层、相互依赖或未知轨道不强行改标签。系统给Dolby/HEVC相同ID不是容器基础层身份的充分证明。
- 不支持/加密/损坏结构不能伪装成功；这是受限格式链，不保证所有手机视频都能处理。

## 时序、音频与发布

解码/编码帧PTS、顺序、样本见证和末帧时长参与精确封装；实际音频样本及PTS受保护，不补静音或裁包掩盖差异。音轨头部时长与实际样本不一致时可记录告警，但有效样本表、可解析编辑、边界和最终回读仍必须满足要求。

可选拍摄元数据迁移失败记录具体问题，不单独阻断完整成片导出；真实编解码、权限、I/O、取消和写后回读失败不会假报成功。发布前完成写入同步和SHA-256回读。位置信息可能保留，分享前请检查。

## 尚需真机验证

本轮不安装/操作手机；AndroidTest仅编译。UI/首帧/播放器、MediaCodec/MediaExtractor/MediaMuxer、P010、HDR屏幕、相册/SAF、长片音画同步、真实原始杜比样本、速度/温升/总内存仍需设备验收。发生失败请提供应用版本、包名、完整新日志；必要时再提供获准且无隐私、未经转码的短原片。
