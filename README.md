# 传奇一瞬 · 源码公开版

在 Android 手机上离线处理照片与视频：照片调色、景深虚化、主体保护、智能构图，以及视频 LUT 调色。

**当前源码版本：3.0.0 / 104。** 本仓库是经过筛选的公开版本，不是私有生产工程的完整镜像。

> **公开范围**：保留徕卡冷调、徕卡暖调；新增公开“徕卡一瞬”和“徕卡N瞬”的实现及两份 LUT。
> **不公开**：“传奇一瞬”专属色彩功能、模型、参数/LUT、保护加载实现、签名材料和私人样片。
> 项目名称仍为“传奇一瞬”，不表示同名私有色彩功能已公开。

## 色彩与功能

| 用途 | 可选色彩 | 随仓库提供的资源 |
|---|---|---|
| 照片 | 徕卡冷调、徕卡暖调 | 两份 epoch6 ONNX 调色模型 |
| 照片 | 徕卡一瞬 | `looks/leica-instant-v2.bin` |
| 视频 | 徕卡一瞬、徕卡N瞬 | 上述同一份一瞬 LUT，以及 `looks/leica-n-instant.bin` |

照片与视频“徕卡一瞬”共用同一份 LUT 节点，但视频还包含传递函数、色域与 YUV 转换，不能据此承诺二者编码结果逐字节相同。徕卡N瞬目前是**视频选项**，不额外加入照片风格菜单。

- **照片编辑**：导入后选择处理流程、色彩及参数，再显影；切换风格不自动处理或保存，旧成片保留其实际风格。照片首次默认冷调。
- **景深与主体**：手动对焦、光圈、相对深度与分层光学虚化；主体保护默认关闭，支持多个保护点。深度不是实测米制距离。
- **构图与空间**：构图评分、应用裁框与保存分开；深度空间视图支持旋转、平移、缩放和陀螺仪视差，不是三维重建。
- **照片导出**：SDR 支持 PNG、JPEG、WebP；Android 14+ 支持受限的 SDR 基底 Ultra HDR JPEG 配对处理与导出。显式 HDR 失败不静默转 SDR。非虚化最高 5000 万像素；虚化原图档最高 1250 万像素，另有 2048 / 1024 档；不足时不放大。
- **视频调色**：默认徕卡N瞬，支持显式保存默认选择；导入后请求首帧并保持暂停。使用原尺寸逐帧调色并重编码，检查帧时间戳、样本和音轨，最多 8 个工作线程处理同一帧，不是 8 帧并行。
- **外接模式**：用户主动开启，只处理监听就绪后新增且稳定的照片，不补跑历史；默认保留原片。危险删除选项必须另行确认，重要照片请先备份。

景深、构图、主体保护还需自行准备对应第三方模型；**编译成功不等于这些模型已经齐全**。视频和纯 LUT 调色不需要额外 ONNX 模型。

## 快速开始

需要 JDK 17、Android SDK 35、NDK `27.2.12479018`、CMake `3.22.1`；最低运行系统为 Android 8.0（API 26）。HDR、相册与编解码能力另受系统和硬件限制。

```bash
# macOS / Linux 首次使用
chmod +x gradlew
./gradlew :app:assembleDebug
./gradlew :app:verifyLeicaMath
```

```powershell
# Windows
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:verifyLeicaMath
```

首次构建需要下载依赖；依赖与 SDK 组件准备齐全后才能使用 `--offline`。`local.properties` 中的 SDK 路径只留在本机。完整步骤和 Windows 原生工具路径说明见 [构建指南](docs/BUILDING.md)。

```bash
# 仅核对仓库随附的两份模型和两份 LUT，不下载文件
python tools/check_models.py --bundled-only
```

公开版应用 ID 为 `xyz.shuncongci.leica.v3`，桌面名称为“传奇一瞬 V3 · 公开版”。Debug 使用本机调试签名，Release 默认未签名。**它与私有 V3 成品使用相同应用 ID，但签名不同，不能直接覆盖安装或保证并存**；如需同时保留，请在本地为自己的构建设置不同应用 ID，不要为解决冲突直接卸载并丢失数据。

## 使用与限制

- [照片编辑与外接](docs/EXTERNAL-MODE.md)：操作顺序、权限、元数据和原片处置风险。
- [视频模式](docs/VIDEO.md)：轨道选择、SDR/HDR、杜比兼容基础层与导出。
- [模型和 LUT](docs/MODELS.md)、[机器可读资源清单](models.json)：来源、接口、哈希及许可边界。
- [实现说明](docs/ARCHITECTURE.md)：代码入口、处理链和缓存/发布约束。
- [验证状态](docs/VALIDATION.md)、[发布前检查](docs/RELEASE.md)：已验证项与仍需真机验收的部分。

视频调色会重编码，不是视频无损复制。HDR 视频需要 Android 13+ 及支持 P010 的 10bit 编解码器；不支持时明确停止，不自动降为 8bit 或 SDR。杜比输入仅支持可核验的 Profile 8 兼容基础层转**普通 HEVC**，不保留杜比动态元数据，不宣称原生杜比输出。

应用没有 `INTERNET` 权限，照片与视频在设备上处理；这与构建时联网下载依赖不同。导出可能保留原片 GPS 等信息，分享前请自行检查。最近照片检查点和视频缓存不是加密备份。
