# 版本记录

## 2.5.0 / 58

- 保留徕卡冷调、徕卡暖调两份 epoch6 自有模型及其哈希；五份第三方权重仍不随源码提供。个人非商业许可、既有 Git 历史和公开构建的签名策略保持不变。
- SDR 导出增加 JPEG Q95、WebP Q90/Q95 和系统支持的无损 WebP，默认 PNG。格式切换不重新显影，不偷偷放大已有结果；空间节省值仅为估计。增加导出提交、菜单布局和动画状态检查。
- 加入 Android 14+ 的 SDR 基底 Ultra HDR JPEG 识别、SDR/HDR 配对成片及增益图编码路径。已编辑结果使用成片重新计算增益图，不贴回原片增益图；编码回读检查通过后才发布。能力不支持时明确标注 SDR，取消、I/O 或内存错误不作为成功回退。
- 深度空间预览加入全屏、旋转、平移、缩放、网格和陀螺仪视差。陀螺仪默认关闭，暂停或失焦时停止驱动，可手动校准；不宣称单张照片完成三维重建。
- 加入最近照片会话的本机检查点与恢复；不可变 blob 先落盘，再原子提交清单。损坏记录保留并显式报错，不静默清理或伪造成功。主体分析提供 2048 / 1220 / 720 档位，并补充宽图边缘、缓存及界面状态回归。
- 公开树 1240 项 JVM 测试通过；Debug、未签名 Release、AndroidTest APK 构建成功。核验分别通过同版本官方 ONNX Runtime AAR 的显式离线覆盖和默认 Maven 依赖构建；不依赖开发机私有工程路径。原有合成夹具和两份随附模型未改变。
- 本轮没有进行 Android 真机动态交互、HDR 编解码/显示、相册发布、恢复、陀螺仪、峰值内存或耗时验收。JVM 测试、构建和静态包检查均不代替设备验证；第三方模型缺失时对应功能不能据此宣称可用。

## 2.1.24 / 39

- 新增徕卡冷调（M9/M10系列4.0 epoch6）与徕卡暖调（M9系列3.0 epoch6），均为G_AB，内部FP16、外部FP32；沿用长边1024分析和整数LAB融合，不额外加LUT或纠正器。
- 风格按钮独立于处理流程；仅包含调色时可见，默认冷调并记住选择。切换后点击显影应用；忙碌时禁止切换，旧成片保留并显示实际风格，保存上次不偷偷重跑。
- 生成及构图保留风格快照；切换不清空焦点、深度与主体缓存。2.1.23输出尺寸和参数收起策略保持。
- 当前树删除旧epoch11 ONNX，附两份新的自有调色ONNX，更新models.json、运行时哈希、许可说明及忽略规则；不附原checkpoint、训练集或五份第三方权重，也不重写Git历史。
- 新增ColorStyleTest的23项回归，总计887项JVM测试。两份模型完成32组桌面转换数值检查、8组实际模型＋Kotlin重采样/LAB融合联调；这些不是Android UI、NNAPI、内存、耗时或相册保存验收。
- 个人非商业许可保持；公开工程继续使用Maven依赖/可选本地AAR，Release默认不含作者签名。


## 2.1.23 / 38

本次同步调整输出尺寸策略与参数面板行为，不改主体保护算法、模型或许可。

- 只有包含虚化的流程显示原图像素、长边 2048、长边 1024 三档。切到非虚化时不再受之前选择的 2048/1024 影响，切回虚化仍保留原选择。
- 不选虚化时自动按可用原像素输出，最多 50,000,000 像素；超过上限才等比缩小，小图不放大。已选调色照常执行，不把原像素输出解释为跳过调色。
- 成片成功生成、呈现并提交后自动收起参数；失败、取消和预览不触发。可手动重新展开，换图重新展开。
- 接着构图时临时显示参数及方案，应用后收起，返回/取消恢复进入前状态。应用裁框不重新调色或虚化、不自动保存。
- 新增 PhotoOutputPolicyTest 的 26 项测试，并更新旧测试中与新非虚化尺寸规则冲突的预期。完整 JVM 套件共 864 项；没有删除旧用例或跳过断言。

验证与限制

公开工程使用独立合成测试数据，不附带照片样例。测试入口是 :app:verifyLeicaMath；构建入口是 :app:assembleDebug 和 :app:assembleRelease。Release 默认仍未签名，ONNX Runtime 仍通过 Maven 获取或由使用者显式指定本地 AAR。

当前只随源码提供自有 M9 模型；五份第三方模型仍不附带权重。缺少模型时编译成功不代表完整功能可用，准备方法见 [模型说明](MODELS.md)。

本次未做 HDR、高位深或广色域保留改造，输出仍走现有 8 位 PNG 链路；没有进行手机端 5000 万像素推理峰值内存、耗时或相册保存验收。已有低分辨率结果不会暗中重生成或放大，进一步生成需使用者明确操作。设备验证清单见 [发布检查](RELEASE.md)。
