# 分享与发布前检查

本项目原创部分沿用个人非商业许可，不因源码可下载而获得商业授权。第三方材料保留各自许可证；GAIC 检查点的独立再分发许可仍未确认。

## 1. 审查完整发布树

不仅查看 `.gitignore` 或本次 diff，还要列出全部将提交的文件，包括原有追踪文件和新增文件。运行 `python tools/check_public_source.py`，并人工核对 Git 待提交树与全部二进制文件。

本仓库允许的新增风格资源只有：

- `app/src/main/assets/looks/leica-instant-v2.bin`：照片/视频共用的一瞬 LUT。
- `app/src/main/assets/looks/leica-n-instant.bin`：视频 N 瞬 LUT。

同时保留原有冷暖两份 ONNX。所有资源的长度、SHA-256 和来源说明见 `models.json`。不要打包传奇专属模型/参数/LUT、签名绑定与解密实现、生成密钥、keystore、账号令牌、个人路径、私人照片/视频、训练集、日志、缓存、APK/AAB 或整个本地核验目录。历史通用类名和合成数值夹具可保留，不能借其名称把私有材料混入。

不新增分发第三方权重。使用者自行取得权重也须检查对应许可；来源链接、代码许可或哈希都不是完整权利链保证。保留 `LICENSE`、`THIRD_PARTY_NOTICES.md` 和文件原始版权/许可头。

## 2. 核验与构建

```bash
python tools/check_models.py --bundled-only
python tools/check_public_source.py
./gradlew :app:verifyLeicaMath :app:compileReleaseKotlin :app:compileDebugAndroidTestKotlin :app:assembleRelease
```

检查版本、Manifest/权限、R8 后 JNI 注册名称、四种 ABI 的原生库、16 KiB 对齐、资源哈希及 APK 内容。Release 默认未签名；使用自己的签名，不复制作者的密钥。公开 V3 与私有 V3 同应用 ID，不同签名不可直接覆盖；如需并存应先更改本地应用 ID，不以卸载/清数据解决冲突。

重新导出的模型/LUT先核对接口、精度、数值、尺寸、哈希和许可，再更新清单及消费端常量。不要取消校验或以预览替代完整成片。

## 3. 必须另行完成的真机检查

- 照片：三种公开风格选择与记忆、忙碌/取消/换图/旧成片标签、RAW/DNG 主图尺寸、裁框与非虚化 50MP / 虚化 1250 万上限、各档光圈、多个保护点及页面/进程恢复。
- HDR：受支持 Ultra HDR 来源、真实增益图预览、显式 HDR/SDR 分离、失败不转 SDR、各格式保存与元数据回读、相册真实显示；不是只看标志或窗口请求。
- UI：窄屏/横屏/大字体、返回/前后台、动画开关、空间视图归位、无障碍和真实内存/温升/耗时。
- 视频：导入首帧保持暂停，播放/拖动/原片成片切换；两种 LUT、默认选择与显式保存；独立多轨选择、长片音画同步、SDR 和 PQ/HLG P010 10bit 编解码，取消/失败保留原片和上次完整成片。
- 杜比：仅核验 Profile 8 兼容基础层转普通 HEVC，不含旧 RPU/杜比动态元数据；Profile 5、增强层、未知/依赖轨道不能强行改标签。真实原始样本未测就不能声称全面兼容。
- 外接：就绪前基线跳过、稳定新片、连拍/索引延迟、停止/重启不补历史、权限撤销和 SAF/媒体库提供器。默认保留原片；删除另行危险确认与系统授权，先备份，只用可丢弃的新片测试。附加数据未完整转存的风险必须如实提示，不补删旧片。

系统权限和安全确认由本人操作，不绕过。应用没有 INTERNET/CAMERA 权限，不读取实时定位；构建依赖联网和原片 GPS 元数据是另外的边界。导出可能含位置，分享前请检查。
