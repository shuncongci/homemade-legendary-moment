准备个人安装包时，先核对要打包的模型，运行 python tools/check_models.py，再运行 verifyLeicaMath、assembleDebug 和 assembleRelease。Release 默认未签名，需要使用你自己的密钥签名并妥善保管。自行签名的安装包不能直接覆盖我发布的不同签名版本；卸载前应先确认应用数据是否已备份。

模型重新转换后应核对输入输出、数值误差、精度、动态尺寸及 Android Runtime 兼容性。确认后同步清单和源码哈希，不能通过删除校验来放行。

实际设备还需检查导入、冷调/暖调切换与选择记忆、处理中禁止切换、旧成片标签和保存上次行为、各档光圈、单点与多点保护、移动删除保护点、取消、裁切、虚化三档输出及保存；还要检查非虚化隐藏尺寸选项、原像素/5000 万上限、成功生成后收起参数和构图返回状态。测试手机内存和耗时，不要把 JVM 测试或桌面 ONNX 检查当成真机验收。
