## 构建失败记录与环境边界

最初两轮在 Windows CMake 配置阶段异常退出。当时没有取得整套回归/构建成功结果；失败日志保留在本地，不纳入公开仓库。之后在同一份目录的 ASCII 路径联接、工具路径和隔离 staging/输出/TEMP 环境下，第三轮完整构建通过；加入 NDK NOTICE 后第四轮也完整通过，以上 APK 身份来自第四轮最终产物。不能据此认定前两次失败只有“中文路径”一个根因。

原生路径参数与离线依赖准备见 [构建指南](BUILDING.md)。本机成功不等于已测试全部操作系统或默认 Maven 在线下载路线。GitHub 同步必须在完整候选树与暂存树审查后进行，并回读实际提交、完整树和文件内容；本页本身不是远端推送凭据。

## 未完成的设备与权利验收

本轮**未安装或运行手机**，未处理用户照片/视频。UI、首帧/真实播放器、MediaCodec/MediaExtractor/MediaMuxer、P010/10bit、HDR 显示、系统授权、相册/SAF、外接原片处置、长片音画同步、速度/温升/总内存、50MP 与原始杜比样本均需真机另验。杜比仍只支持可核验 Profile 8 兼容基础层转普通 HEVC，不生成或保留杜比动态元数据。

五份第三方/历史模型权重仍不随仓库提供，缺权重时编译成功不证明相应功能可用。本轮没有重新运行这些模型的完整转换/推理；冷暖模型的历史转换对照属于历史证据。个人非商业许可与第三方权利边界不因测试通过而改变，GAIC 检查点的独立再分发许可仍未确认。

具体设备验收清单见 [发布前检查](RELEASE.md)；历史通过记录只属于 [各自版本](CHANGELOG.md)。
