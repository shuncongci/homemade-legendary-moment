PREFERENCES

工作台设置

处理资源

串行逐帧处理，适合内存较少时使用；并发可提高速度，但需要更多内存。画质与尺寸不变，保存后用于后续任务。

自动模式缺少可用 GPU 时使用 CPU；GPU 可能有极少数 1/255 舍入差异。CPU 精确模式保留原效果。仅影响后续一瞬 / N瞬任务，不自动重算。

导入照片超出上限时，工作图会等比缩小，原文件不变。200 MP 仅为允许导入的像素上限；能否处理及处理速度仍取决于可用内存和设备。

本地动作存档

每个照片或视频文件只保留最近一个完整处理动作。新动作成功后才替换；失败、取消或中断不替换。

照片与视频共用名额，默认10个，支持1–64个（与工作台素材上限一致）。按最近成功完成动作的顺序保留；查看存档不改变顺序。

此项单独保存到当前端口工作区，服务重开仍保留。不保存中间步骤或视频帧。淘汰仅删除动作快照，不删除原片、历史完整成片、已下载文件或旧格式存档；4 GiB会话预算与磁盘保护仍生效。

视频调色帧并发

同时处理的视频帧数，默认8。适用于 CPU 调色；GPU 批次与虚化另行设置。并发越高需要的内存越多，不一定更快；资源不足时会提示。

视频虚化并发

仅影响开启虚化的视频。智能并发按设备余量安排；也可手动输入至少1的整数。较高并发需要更多内存，不一定更快。保存后用于后续任务。
