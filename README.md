# 传奇一瞬

这是我发布的 Android 照片处理应用，主要做调色、景深虚化和智能构图，也可以手动选择需要保持清晰的主体。照片处理在手机上离线完成。

我以个人非商业使用许可公开 2.5.0（versionCode 58）版本的源码，供个人学习、修改和使用。作为本项目的发布者，我提供应用源码和两份自有调色模型；第三方代码和模型的权利仍归各自权利人所有。

源码中不包含安装包、我的签名密钥、照片样例或训练数据。第三方模型不附带权重，来源和准备方法见模型说明。

功能

调色：徕卡冷调 / 徕卡暖调两种独立模型，输出低频色彩后与原图细节融合。包含调色的流程显示二选一按钮，记住上次选择；首次默认冷调。切换后点击显影才应用，不自动处理或保存，旧成片保留并标注其实际风格。

景深：手动选焦点、调整光圈；相对深度配合神经虚化和高光散射生成景深效果。

主体保护：可选功能，默认关闭。支持多个保护点，已完成的点在当前照片会话中缓存，接触主体合并后再参与渲染。

构图：用 GAIC 给候选裁框评分。选方案、应用裁框和保存是分开的操作；应用已有成片的裁框不会重新调色或虚化。

导出：只有选择虚化时显示原图像素、长边 2048 和 1024 三档。不选虚化时自动保留可用原像素，最高 5000 万像素；超过上限才等比缩小，小图和裁框内像素不足时不放大。SDR 成片可选 PNG、JPEG Q95、WebP Q90/Q95 或受系统支持的无损 WebP；格式选择不重新运行模型，体积提示只是估计。Android 14 及以上增加 SDR 基底 Ultra HDR JPEG 的识别、配对处理和导出；实际目标具有 HDR 成片时，导出菜单显示 Ultra HDR JPG。不是对任意 HEIF、PQ、HLG、高位深或广色域原编码的无损保留。

参数：成片成功生成并呈现后自动收起，失败或取消不触发。需要接着构图时仍显示方案，应用后再收起；可手动通过“参数”重新展开，换图重新展开。

空间预览：深度网格支持旋转、平移、缩放和全屏；全屏陀螺仪视差默认关闭，可校准。它是单张照片的深度展示，不是三维重建。

会话恢复：在本机私有目录保留最近一张照片的检查点，不积累历史。先完成不可变像素文件，再原子提交清单；损坏记录显式报错并保留证据。它不是加密备份，也不保证来源访问权限被撤销后仍能继续处理。主体分析可选长边 2048、1220 或 720，默认 2048；改变分析档位需重新计算相应缓存。

本次改动和验证边界见 [版本记录](docs/CHANGELOG.md)。

App 没有联网权限。照片在设备上处理；构建时下载依赖、开发者自行准备模型，与 App 运行时联网是两回事。

开始使用

需要 JDK 17、Android SDK 35 和支持 AGP 8.7 的 Android Studio；最低运行版本是 Android 8.0（API 26）。Gradle Wrapper 已包含。

```bash
# macOS / Linux 首次使用时
chmod +x gradlew
./gradlew :app:assembleDebug
```

Windows 使用：

```powershell
.\gradlew.bat :app:assembleDebug
```

第一次构建会下载依赖。SDK 路径由 Android Studio 写入本地 local.properties，不要提交这个文件。

缺少第三方模型时仍可编译，但这不代表对应功能能运行。只使用调色时可用已包含的模型；景深、智能构图、主体保护分别需要额外资产。先看模型说明（docs/MODELS.md），准备后用 python tools/check_models.py 检查。

详细步骤见构建说明（docs/BUILDING.md）。代码入口和处理尺寸见实现说明（docs/ARCHITECTURE.md）。

测试

```bash
./gradlew :app:verifyLeicaMath
```

当前公开工程的 1240 项 JVM 测试已通过，Debug、未签名 Release 和 AndroidTest APK 均已构建。可在电脑上运行单元测试，检查图像处理算法和状态逻辑；构建 AndroidTest APK 不等于运行了设备测试。本版本未重新做 Android 真机界面、HDR 编解码、恢复、内存或性能验收。测试数据的说明见 docs/BUILDING.md。

模型与依赖

第三方模型包括 Depth Anything V2 Small、BokehMe ARNet、GAIC MobileNetV2、SAM 2.1 Tiny 和 ViTMatte Small。原仓库、检查点、输入输出约定和已使用的 ONNX 哈希列在模型说明（docs/MODELS.md）与 models.json 中。

ONNX Runtime 通过 Maven 获取，不随源码带 AAR。相关版权和许可说明见第三方声明（THIRD_PARTY_NOTICES.md）。
