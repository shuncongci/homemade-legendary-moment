# 照片编辑与外接 · 3.0.0 公开版

## 外接使用

1. 从编辑页打开“外接”；打开页面、自动发现或选择目录都不会启动处理。
2. 选择相机目录、冷调/暖调/徕卡一瞬、全部SDR或优先HDR、默认SDR格式。照片与外接不提供视频专用徕卡N瞬，也不提供传奇专属色彩。
3. 按页面说明自行授权目录/照片读取、原片已有GPS元数据、通知、悬浮窗或后台权限。原片GPS权限不是实时定位。授权弹窗必须本人确认。
4. 默认同时保留原片和成片。若选择成功保存后删除原片，需要阅读风险提示后单独确认，旧版删除选择升级后不会自动继承。重要照片请先备份：明确同意后，即使动态照片视频、源 HDR、人像编辑数据或部分拍摄信息没有全部转存，也会继续尝试删除。删除可能不可恢复；不接受这些风险就保留原片。
5. 页面置顶状态岛可开始或停止监听；明确开始后先完整建立现有照片基线，显示“监听已就绪”后再拍照。至少三次且跨三秒稳定检测后串行处理，仅自动调色、不虚化。
6. 在持续通知或外接页面停止。停止期间照片、旧队列、重启前照片绝不补跑；延迟索引/时间不精确时可能保守漏收边界照片。

输出位于Pictures/传奇一瞬/外接/，自动排除自身输出，不能用输出目录循环监听。源文件与发布结果的身份、SHA-256、拍摄元数据回读未满足时不删除原片；处置失败保留并提示，不重显影已成功输出。Android 11+媒体库尝试系统回收站；直接文件路径可能永久删除，SAF依提供器，不承诺全部可恢复。停止或重启不恢复旧删除授权；不确定结果人工核对，不自动重试。

## 编辑与标识

HDR输入仍明确选择HDR或SDR显影；显式HDR失败不静默降为SDR。外接优先HDR仅对能力不支持作SDR回退，取消/I/O/OOM不是成功回退。

编辑导出标识默认关闭，开启后SDR只显示JPEG，HDR仍是真实Ultra HDR JPEG；不适用格式保留位置并禁用，关闭标识后恢复之前SDR格式。只注入候选ExifIFD 0x88B0单字节最低位，不在画面加字、不伪造机型/GPS，也不复制样例的其他私有字段。EXIF回读通过不等于小米相册显示，官方协议未确认，设备识别未验收。

## 呈现与监测

参数采用可收回覆盖面板，照片保留完整预览容器，选择/说明/更多沿真实入口展开收回；真实成片到达后连续缩放/裁剪到对比视图，不用SDR截图冒充HDR过渡。关闭动画、取消和前后台分支保留，真实触控组合仍待设备验收。

编辑“监测”和外接设置可分别开启静音运行参数通知；默认关闭，约2秒刷新本进程CPU、PSS/Java/native和手机可用内存及系统热状态。热状态不是摄氏度，弹窗CPU为总容量占比、通知主行是单核等效；详情按需采样。通知/悬浮窗拒绝不绕过，不承诺被OEM杀进程后继续。

## 照片编辑顺序

导入照片 → 选择流程与风格 → 按需设置焦点/光圈/主体保护 → 选择 SDR/HDR 并显影 → 可选构图 → 导出。风格切换只改变下次显影，旧成片不自动重算；保存上次结果保持其实际风格。

非虚化保留可用原像素、最高5000万；虚化原图档完整工作画面最高1250万，另可选2048/1024，不放大补像素。RAW/DNG 依赖系统完整主图解码，拒绝把小预览当原像素。最近照片恢复不是长期备份；主体保护默认关闭，多点仅补算缺失项。

相册元数据标识不在画面加水印，不保证厂商相册识别。元数据兼容告警应查看完整记录，真实权限、I/O、取消或发布失败不报成功。导出可能保留原有位置等信息，请在分享前检查。

## 验证边界

当前 JVM、编译与构建结果见 [验证状态](VALIDATION.md)。本轮未在手机执行 UI、系统权限、相册/HDR显示、外接删除、50MP、峰值内存或温升验收；设备测试仅编译。不要在未备份的私人照片上验证删除功能。
